1. pastikan versi node.js adalah 22.15.0
2. jalankan comman "npm install" di terminal pada di folder backend dan frontend
   backend :
   - cd D:\dms\backend

  frontend :

  backend :
  - cd D:\dms\backend
  - node server.js
  frontend :

  - npm run build
  - npm run dev
5. Buka browser jalankan localhost:3000
